# نظام تحليل ترحيل المتأخرات الشهري

Monthly Delinquency Migration Analysis System — the default application of this site:
<https://fadiramzy.github.io/test/>

تطبيق ويب عربي (RTL) يعمل بالكامل داخل المتصفح دون خادم؛ البيانات تُحفظ محليًا في IndexedDB.

## ما الذي يقدّمه

| القسم | المسار | الوظيفة |
| --- | --- | --- |
| لوحة المقارنة | `#/` | مقارنة أي شهرين: العملاء والمبالغ لكل شريحة، صافي التغير، مؤشرات NPL، ملخص تنفيذي، مصفوفة الترحيل، أداء الفروع، تصدير Excel |
| إدخال البيانات الشهرية | `#/entry` | عدد العملاء ومبلغ المتأخرات لكل شريحة ولكل فرع، مع قائمة عملاء اختيارية |
| المقارنات المحفوظة | `#/saved` | نسخ مجمّدة من المقارنات للرجوع إليها |
| البيانات والنسخ الاحتياطي | `#/data` | تنزيل/استعادة نسخة احتياطية، اسم الجهة، بيانات تجريبية، حذف البيانات |

شرائح التأخير الخمس: **1–30**، **31–60**، **61–90**، **91–120**، **أكثر من 120 يومًا (NPL)**.

حدود التحليل المعلنة داخل النظام: من الإجماليات الشهرية يُحسب **صافي التغير** فقط؛ حركة الترحيل الفعلية
بين الشرائح تظهر فقط عند إدخال قوائم العملاء للشهرين، وانخفاض الرصيد لا يُعرض على أنه تحصيل مؤكد.

## بنية المستودع

- `index.html` → `src/delinquency/` — النظام الجديد (مستقل: لا يستورد أي ملف من خارج مجلده).
  - `lib/` المحرك الحسابي، الترحيل، الملخص، مولّد Excel، النسخ الاحتياطي
  - `db/` قاعدة IndexedDB مستقلة باسم `risk-delinquency-analysis`
  - `pages/`, `components/`, `ui/`, `styles/` الواجهة
- `employees.html` → `src/main.tsx` — النظام السابق (إدارة مسؤولي المخاطر) محفوظ كما هو ببياناته،
  ويُفتح من <https://fadiramzy.github.io/test/employees.html>.

## التشغيل

```bash
npm ci
npm run dev        # خادم التطوير
npm run typecheck
npm test
npm run build      # ينتج dist/ (index.html + employees.html)
```

النشر تلقائي إلى GitHub Pages عند الدفع إلى `main` عبر `.github/workflows/deploy.yml`.
