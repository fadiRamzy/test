# نظام تحليل ترحيل المتأخرات الشهري

Monthly Delinquency Migration Analysis System — the default application of this site:
<https://fadiramzy.github.io/test/>

تطبيق ويب عربي (RTL) يعمل بالكامل داخل المتصفح دون خادم؛ البيانات تُحفظ محليًا في IndexedDB.

## ما الذي يقدّمه

| القسم | المسار | الوظيفة |
| --- | --- | --- |
| لوحة المقارنة | `#/` | مقارنة أي شهرين: عدد العملاء والمبالغ لكل شريحة والفرق والنسبة، مع جدول مقارنة الفروع وتصدير Excel |
| إدخال البيانات الشهرية | `#/entry` | عدد العملاء ومبلغ المتأخرات لكل شريحة ولكل فرع، وجدول الشهور المحفوظة (تعديل/حذف) |
| المقارنات المحفوظة | `#/saved` | نسخ مجمّدة من المقارنات للرجوع إليها |
| النسخ الاحتياطي | `#/data` | ثلاثة أزرار فقط: تصدير Excel، تنزيل نسخة احتياطية JSON، رفع نسخة احتياطية JSON |

شرائح التأخير الخمس: **1–30**، **31–60**، **61–90**، **91–120**، **أكثر من 120 يومًا (NPL)**.

### تقرير Excel

ورقة واحدة «تقرير المتأخرات»، كل صف فرع واحد، والأعمدة بهذا الترتيب:

`الفرع | 1-30 | 31-60 | 61-90 | 91-120 | NPL | مبلغ 1-30 | مبلغ 31-60 | مبلغ 61-90 | مبلغ 91-120 | مبلغ NPL | إجمالي العملاء | إجمالي المبلغ`

الأعمدة الخمسة الأولى أعداد العملاء والخمسة التالية مبالغ المتأخرات. يحتوي التقرير ثلاثة جداول تحت بعضها:
الشهر السابق، الشهر الحالي، ثم الفرق (الحالي − السابق)، ولكل جدول صف «الإجمالي» عند وجود أكثر من فرع.
الإجماليات والفروق صيغ Excel حية؛ الفرع الذي لا بيانات له في أحد الشهرين يظهر «—» ولا يدخل في إجمالي الفرق.

### حفظ البيانات

كل البيانات في IndexedDB داخل المتصفح (قاعدة `risk-delinquency-analysis`) وتبقى بعد تحديث الصفحة وإغلاق المتصفح.
النسخة الاحتياطية JSON تحمل كل بيانات النظام. عند الرفع: السجل الموجود لنفس الشهر والفرع يُستبدل بنسخة الملف،
وما ليس في الملف يبقى كما هو، والعملية كلها تتم في معاملة واحدة (كلها أو لا شيء).

## بنية المستودع

- `index.html` → `src/delinquency/` — النظام الجديد (مستقل: لا يستورد أي ملف من خارج مجلده).
  - `lib/` المحرك الحسابي، مولّد Excel، النسخ الاحتياطي
  - `db/` قاعدة IndexedDB مستقلة باسم `risk-delinquency-analysis`
  - `pages/`, `components/`, `ui/`, `styles/` الواجهة
- `employees.html` → `src/main.tsx` — النظام السابق (إدارة مسؤولي المخاطر) محفوظ كما هو ببياناته،
  ويُفتح من <https://fadiramzy.github.io/test/employees.html>.

## التشغيل

```bash
npm ci
npm run dev        # خادم التطوير
npm run typecheck
npm test
npm run build      # ينتج dist/ (index.html + employees.html)
```

النشر تلقائي إلى GitHub Pages عند الدفع إلى `main` عبر `.github/workflows/deploy.yml`.
